Method

What the model is doing

01

Load & clean

The mall dataset contains 200 customers with age, gender, annual income and spending score. The browser reads the original CSV from this repository.

02

Standardize

Each feature is converted to the same scale so income does not dominate smaller numeric features. Gender is encoded as a binary feature for this educational model.

03

Cluster

K-Means repeatedly assigns customers to the nearest centroid and then updates each centroid until assignments stop changing or the iteration limit is reached.

04

Profile

Cluster averages are converted into simple business-friendly labels such as high-value, opportunity, growth or mainstream segments.

Scope: This is an educational segmentation demo built from a public mall dataset. Cluster labels are descriptive summaries, not claims about real customers or campaign outcomes.
